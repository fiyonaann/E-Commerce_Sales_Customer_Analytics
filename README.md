\# E-Commerce Sales \& Customer Analysis



\## 📊 Project Overview



This project analyzes e-commerce sales, customer behavior, payment methods, products, sellers, and reviews using the Olist Brazilian E-Commerce dataset.



The project combines \*\*MySQL\*\* for data analysis and \*\*Power BI\*\* for interactive dashboard visualization.



\## 🛠️ Tools \& Technologies



\- MySQL

\- DBeaver

\- Power BI

\- MySQL ODBC

\- SQL

\- Power Query

\- DAX



\## 🗄️ Database Tables



The MySQL database contains:



\- customers

\- orders

\- order\_items

\- payments

\- products

\- sellers

\- reviews

\- category\_translation

\- geolocation



\## 📈 Power BI Dashboard



The dashboard provides analysis of:



\- Total Orders

\- Total Revenue

\- Average Order Value

\- Total Customers

\- Revenue by Payment Method

\- Top Sellers by Revenue

\- Revenue by Product Category

\- Top Customers by Spending

\- Reviews by Rating

\- Average Product Price

\- Monthly Revenue

\- Top Products by Revenue

\- Orders by Status

\- Revenue by Customer State



\## 🔍 SQL Analysis



SQL queries were used to analyze:



\- Payment method performance

\- Review score distribution

\- Top products by revenue

\- Top product categories

\- Seller performance

\- Customer spending

\- Customer order frequency

\- Average order value
